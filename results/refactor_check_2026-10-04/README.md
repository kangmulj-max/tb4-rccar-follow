# 리팩터(R1) 실행본 검증 — v3_safe + yolo12n, 2026-10-04

리팩터 후 실행본(`follow_object_node_v3_safe.py`)으로 대표 시나리오 8 종을 1 회씩 실행하고, 리팩터 전 v3_safe 의 같은 시나리오 결과와 비교.
비교 기준은 가능하면 같은 날 4 차 회차, 없으면 전날 3 차 회차. 시뮬 실행마다 추종률은 ±10 %p 흔들리므로 **충돌 여부·정지 동작이 같은지**를 본다.

- pole·depthstop 은 12n 이 2 m 밖 정지 RC카를 처음부터 못 잡아 출발하지 않으므로(정지 장치가 시험되지 않음) 11n 으로 따로 실행.
  pole: 정면 폴 앞 정지 (최대 속도 0.18 m/s 로 접근 후 정지, 전과 같음). depthstop: depth 를 잃자 정지 (S2), 충돌 없음.
- shutdown: 주행 중 SIGINT → 노드 로그 `shutdown: stop` 확인 (S9 정지 명령 전송). 추종 유지율 차이는 종료 시점에 따른 값이라 의미 없음.
- approach 충돌은 리팩터 전에도 같은 결과 (RC카가 돌진하고 뒤가 막힌 상황, CODE_REVIEW_GUIDE 3-2 의 알려진 한계).
- 센서 TF: 모든 실행에서 `lidar TF ok`, `camera TF ok` 로그 → R1 의 TF 경로로 장착값을 읽음 (기본값 사용 경고 없음).

**결론: 8 개 시나리오 모두 충돌 여부와 정지 동작이 리팩터 전과 같다.** 추종 유지율 차이(−7~+8 %p)는 회차 변동(±10 %p) 범위.
